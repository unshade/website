Terraform est un outil open source d'infrastructure as code créé par HashiCorp. Il permet de définir et de provisionner de l'infrastructure via un langage de configuration de haut niveau, le HCL (HashiCorp Configuration Language). Terraform gère des ressources externes (infrastructure cloud publique ou privée, équipements réseau, SaaS, PaaS) via un modèle de « providers ».

Ce projet est un provider Terraform pour Infomaniak, hébergeur web et fournisseur de services cloud suisse. Il est écrit en Go avec le Terraform Plugin SDK (tfsdk). Il permet de gérer des ressources Infomaniak comme des clusters Kubernetes, des clusters de bases de données et d'autres services cloud directement depuis Terraform.

Développé dans le cadre de mon travail chez Infomaniak, en tant qu'ingénieur logiciel dans l'équipe Cloud-Computing.
